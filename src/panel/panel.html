Onboard your agents

Give each intern its setup prompt once. Connected agents (anything that can make HTTP calls: custom GPTs with actions, Claude with tools, scripts) then work hands-free. They pull their inbox, read shared context, complete tasks, delegate to teammates and write to the log. If an agent can't make HTTP calls, give it the Offline pack instead and paste its results back below.

Delivery decides who does the work. API: this server calls the model itself. Inbox: the task waits for the external agent.
